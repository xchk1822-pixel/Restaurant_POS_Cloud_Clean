# 2026-10-25 盘点原子提交与调拨输入修复

## 范围

- 仓库盘点和冰箱盘点改为云端事务提交，避免旧页面覆盖新库存。
- 盘点提交增加稳定幂等编号、基准值冲突检测和离线草稿恢复。
- 调拨数量输入框默认空值并自动聚焦，可直接键盘输入和覆盖修改。
- 未修改任何现有库存数量，也未提交测试盘点或测试调拨。

## 根因

- 原盘点流程分步写入库存、历史和出入库记录，多终端并发时可能部分成功或旧值覆盖新值。
- 原调拨数量默认值为 `1`，直接输入会拼接成 `12` 等数值；超过库存后输入被静默拒绝，看起来像键盘卡住。
