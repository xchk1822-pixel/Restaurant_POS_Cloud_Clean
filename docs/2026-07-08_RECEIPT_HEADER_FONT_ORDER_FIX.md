# 2026-07-08 小票抬头、清晰度、订单号修复

## 范围
- 只处理 POS 收银小票打印链路和老板后台分店编辑里的小票设置字段。
- 未修改订单、支付、库存扣减、同步、员工管理等业务逻辑。

## 已修复
1. 小票抬头不再自动套用分店名称。
   - 打印优先读取分店记录里的 `receiptName`。
   - 如果未设置，默认显示 `Restaurante Chino`，避免把 `BLUEFIELDS` 等分店名当成品牌抬头。
2. 老板后台分店编辑新增小票专用字段。
   - 小票抬头名称：`receiptName`
   - 小票副标题：`receiptSubtitle`
   - 小票电话：`receiptPhone`
   - 小票地址：`receiptAddress`
   - 小票底部文字：`receiptFooter`
3. 本地打印桥的小票文本改为完整小票格式。
   - 使用 ESC/POS 初始化、居中、加粗、双高指令提升热敏打印清晰度。
   - 日期和订单号拆成两行，订单号显示为 `Pedido: 070800`，避免右边被裁切。
4. 浏览器备用打印版式收窄到安全可打印宽度。
   - 80mm 小票版心从接近满宽调整为更安全的 72mm。
   - 订单号行增加不溢出处理。

## 使用说明
- 老板账号进入 `分店管理`，编辑对应分店。
- 填写 `小票抬头名称` 后保存，POS 打印会使用该名称。
- 每家分店可以单独填写小票电话、地址、副标题和底部文字。
