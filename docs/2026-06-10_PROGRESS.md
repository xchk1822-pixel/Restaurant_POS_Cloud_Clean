# 2026-06-10 Progress Notes

## 已完成

- 库存模块：物品管理、菜品管理、仓库盘点、冰箱盘点、供应商管理已改为分店隔离的云端/本地存储模式，并增加手动刷新入口，减少旧本地数据覆盖云端新数据的问题。
- 菜品图片：新增浏览器端压缩，保存缩略图和中图；图片文件上传到 Firebase Storage，菜单记录只保存 URL 和路径。
- 菜品图片跨终端：已启用 Firebase Storage，并部署菜单图片专用规则。A 终端上传后，B 终端菜品管理和 POS 点餐列表可读取云端图片。
- POS 菜品图片展示：菜品图片在点餐卡片中显示，名称和价格覆盖在图片上方，图片使用 contain 显示，避免裁切过多。
- 图片上传稳定性：在线上传失败时不再静默保存为本地成功，避免 A 端本地缓存可见、B 端无图的假同步。离线场景仍保留本地待上传。
- 订单库存扣减：堂食、打包、外卖统一为订单完成时扣减库存；支付不扣减，便于顾客先支付后加菜。
- 打包/外卖订单：补充已取餐/完成入口，完成后触发与堂食一致的库存扣减。
