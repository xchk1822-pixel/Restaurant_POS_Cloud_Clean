# 库存流水箭头层级与数量符号修复

日期：2026-10-26

## 修复范围

- 仅修改库存管理的出入库记录列表及对应防回归测试。
- 修复列表滚动时，行内箭头穿透并显示在固定表头上方的问题。
- 数量列保留业务符号：入库 `+`、出库 `-`、调拨 `±`、盘点显示实际增减差额。
- 盘点库存增加使用右箭头，库存减少使用左箭头；箭头颜色继续跟随类型颜色。
- 未修改库存写入、同步、扣减、盘点、采购或调拨业务逻辑。

## 原因与处理

行内箭头使用 CSS `transform` 后形成独立层叠上下文，在滚动容器中可能覆盖粘性表头。处理方式为移除行内箭头的 `transform`，并为每个表头单元格设置固定层级和不透明背景。

## 验证

- 定向测试：`304/304` 通过。
- 生产构建：通过。
- 真实浏览器：登录店长账号后打开出入库记录并滚动列表，确认箭头不再覆盖表头。
- 真实数据视图：确认入库、出库、调拨、盘点四类数量符号及盘点方向箭头正确。
